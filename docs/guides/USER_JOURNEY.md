# Real-life user journey

## Goal

Turn a mixed folder of local documents into a clear case overview, a timeline and a handoff package.

## Normal journey

1. Start the organizer and open the local browser page.
2. Add several safe/demo documents.
3. Bring the waiting files into the case.
4. Create the document overview.
5. Review filenames, groups and notes.
6. Mark two documents for the handoff.
7. Create the timeline and add one event linked to the relevant document.
8. Add a person or organization if it helps explain the case.
9. Create the handoff package.
10. Open the handoff folder and review the result before sharing anything.

**Successful end result:** the selected documents are packaged for handoff, the local case remains organized, and the original imported material stays traceable.

## Typical integrity problem

If an imported original was changed after import, the organizer may refuse to export it.

That is intentional. The useful response is:

1. do not bypass the warning
2. identify which file changed
3. decide whether it should be re-imported or restored
4. rebuild/review the affected case data
5. create the handoff again only after the file state is understood

## Stop and return later

Stop the UI with `Ctrl+C`.

Later run `python run.py ui` or the normal platform launcher. Your local case workspace remains available.
